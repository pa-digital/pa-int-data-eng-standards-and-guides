# Governance

## Purpose

Define how datasets, pipelines, and data products are managed and owned across the platform.

## Why This Is Important

Governance creates accountability and consistency. It ensures data can be trusted, understood, and managed throughout its lifecycle.

## Ownership

Every dataset must have:
- Owner
- Purpose

## Lineage

- Data flow must be traceable
- Transformations documented

## Environments

- Separate dev, test, prod
- Controlled promotion required


## Good Example

Every dataset has:

- An owner
- A documented purpose
- Defined consumers
- Traceable lineage

## Bad Example

Datasets exist without documentation, ownership, or an understanding of where the data originated.
